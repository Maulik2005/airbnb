# Listing interactions

- Hero image and Show all photos open the photo tour.
- A photo inside the tour opens the lightbox at that index.
- ArrowLeft and ArrowRight move within the same 21-photo sequence.
- Escape closes the lightbox first and the photo tour second.
- Focus returns to the button that opened the overlay.
- Reservation and report calls go to the Node API.
