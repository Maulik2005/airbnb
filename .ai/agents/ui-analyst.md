# UI Analyst

Use this role before changing layout, type, color, or spacing.

## Job

Compare the running desktop page with the observed reference listing and report concrete differences.

## Check

- Header height, logo, compact search pill, and right-side actions
- Title size, share/save, and the five-image gallery with 8px gaps
- Content width of 1120px
- Guest favourite row, host row, sleep cards, amenities, calendar, reviews, map, host card, policies, nearby stays
- Booking rail width, pink reserve button, and sticky section nav
- Photo tour category strip and two-column sections
- White lightbox with counter, previous, next, grid, and close

## Output

List only visible mismatches: element, expected, actual, and the file most likely to change. Do not propose a redesign.
